# SpendLayer

SpendLayer is an AI spend audit platform that helps startups identify unnecessary AI tooling costs and optimization opportunities.

Users enter their AI tooling stack, spending, and team size to receive actionable savings recommendations and personalized audit summaries.

## Stack
- Next.js 16
- TypeScript
- Tailwind CSS
- shadcn/ui
- Zustand
- Supabase
- Vitest

## Status
Phase 1 foundation completed.
